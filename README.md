# Rakshit Chaturvedi — Personal Portfolio

A responsive personal portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Font Awesome

## Folder structure

portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── profile.jpg
    └── Rakshit_Chaturvedi_Resume.pdf

## How to run

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.

Recommended VS Code extension:
- Live Server

Then right-click `index.html` → Open with Live Server.

## Where to edit

### Name / About / Projects / Education
Edit `index.html`.

### Colors / Layout / Responsive design
Edit `css/style.css`.

The easiest color to change is:

--accent: #00e5ff;

### Animations / Mobile menu / Typing effect / Contact form
Edit `js/script.js`.

### Profile photo
Replace:

assets/profile.jpg

with your own photo while keeping the same filename.

### Resume
Replace:

assets/Rakshit_Chaturvedi_Resume.pdf

with your updated resume if needed.

## Contact form

The current form uses `mailto:` and opens the visitor's email client.
For a server-based form later, connect Formspree or your own backend.

## Important

Project cards currently do not contain live GitHub/demo links because those links were not provided in the resume. Add them inside `index.html` when available.
